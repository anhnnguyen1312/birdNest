## :clipboard:Introduction 
The system implements **authentication and authorization** using **Access Tokens and Refresh Tokens stored in HTTP-only cookies**, combined with **OAuth (Google, Facebook)** for third-party sign-in. Core features include product management,Toggle Theme, Autocomplete search, shopping cart, order processing, payment integration, send email and **real-time chat** for instant communication.

Beyond the purchasing flow, the project also integrates **blog, comments, and feedback** functionalities, and leverages a combination of **SSR and CSR** to improve SEO and overall performance.

## :wrench:Technologies
:point_right: Front-end:TypeScript, Nextjs framework, TailwindCss, Mui

:point_right:Back-end: Nextjs framework, ORM(Sequelize)

:point_right:Database: Postgresql, Navicat

:point_right: Other: Cloundinary, Postman

:point_right: Deploy platform: Supabase(postgresql db), Vercel
